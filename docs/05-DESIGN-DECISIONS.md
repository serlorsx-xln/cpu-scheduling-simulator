# 5. เหตุผลการตัดสินใจเชิงออกแบบ (Design Decisions)

> สรุปเหตุผลของการตัดสินใจแต่ละจุดไว้ที่เดียว เพื่อใช้อ้างอิงตอนนำเสนอหรือแก้ไขภายหลัง

| # | การตัดสินใจ | เหตุผล |
|---|---|---|
| 1 | อัลกอริทึมเป็น pure function แยกจาก React (`lib/scheduling/`) | ทดสอบด้วย Vitest ได้ตรง ๆ ตามโจทย์ข้อ 1.6; นำไปรันบน server/API ต่อได้ภายหลังโดยไม่แก้อะไร |
| 2 | `AT = 0` ไม่อยู่ใน type ของโปรเซส | โจทย์ fix ไว้แล้ว ไม่ควรพาค่าคงที่ไปหลอก ๆ ในตรรกะ — ถ้าต่อยอดรองรับ AT ภายหลัง เพิ่ม field เดียวใน `ProcessInput` |
| 3 | คำนวณ TAT/WT/AVG ที่ `simulate.ts` จุดเดียว ไม่ใช่ในตัวอัลกอริทึม | สูตรเป็นของโจทย์ ไม่ใช่ของอัลกอริทึม; แก้สูตรที่เดียว, ทุกอัลกอริทึมใช้สูตรเดียวกันเสมอ (ดู [04-DATA-MODEL §4.4](04-DATA-MODEL.md)) |
| 4 | บันทึก `GanttSegment[]` ระหว่าง simulate ทุกอัลกอริทึม | RR ใช้อยู่แล้ว, FCFS/SJF ต้นทุนไม่กี่บรรทัด; UI วาด Gantt จากข้อมูลชุดเดียวกัน และใช้ invariant "Σ ความยาว segment = ΣBT" ตรวจความถูกต้องได้ |
| 5 | SJF ใช้วิธี sort ด้วย key `(BT asc, id asc)` แล้วรันแบบ FCFS | เมื่อ AT = 0 ทุกตัว ผลเหมือนการเลือกแบบ greedy ทีละครั้ง แต่โค้ดสั้นและ deterministic ชัดเจน (tie-break ด้วยเลขโปรเซส) |
| 6 | RR ใช้ ready queue วนธรรมดา ไม่จำลอง arrival ระหว่างทาง | AT = 0 ทุกโปรเซสพร้อมตั้งแต่ต้น ไม่มีใคร "มาถึง" ระหว่าง quantum กฎ priority ของโปรเซสมาใหม่จึงไม่มีผลต่อลำดับ |
| 7 | Validation เป็น module แยก คืน `ValidationIssue[]` ไม่ throw | ทดสอบทีละกฎได้, UI แสดง error รวมทีเดียว, `processId` ช่วยให้ highlight แถวที่ผิดได้ตรงจุด |
| 8 | ไม่ใช้ `alert()` ใช้ inline error + กล่องสรุป | UX ดีกว่า — บอกช่องที่ผิดตรงจุด ผู้ใช้แก้ได้ทันทีโดยไม่ต้องปิด dialog |
| 9 | ไม่มี API route / ฐานข้อมูล / env | คำนวณบน client ทั้งหมด ลดต้นทุน setup — เปิดใช้งานง่ายตามเงื่อนไขโจทย์ |
| 10 | ไม่ใช้ state library | state ทั้งหมดอยู่ในหน้าเดียว `useState` พอ — ใส่ Redux คือความซับซ้อนที่ไม่มีใครได้ประโยชน์ |
| 11 | Tailwind + ESLint ค่า default ของ create-next-app | มากับ template ไม่ต้องเพิ่ม dependency สถาปัตยกรรม ลดงาน setup |
| 12 | BT โหมดสุ่มแสดงในช่อง readonly ไม่ซ่อน | ผู้ใช้ต้องเห็นชุดข้อมูลเดียวกันที่ใช้คำนวณ เพื่อจด/ถ่ายภาพไปตรวจด้วยมือได้ |
