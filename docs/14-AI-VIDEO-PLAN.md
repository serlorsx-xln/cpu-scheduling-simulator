## ขั้นตอนเตรียมก่อนกด Record (เรียงตามลำดับ)

1. **เปิด session แชทจริงไว้ล่วงหน้า:** `claude --resume d82bbb0d-3e20-4f19-8246-3b8243709db1` — ใช้เลื่อนดู prompt/คำตอบจริงในฉาก 2, 3, 7 (อย่าพิมพ์อะไรเพิ่มใน session นั้นระหว่างอัด)
2. **ซ้อมพิมพ์ prompt สด 1 ครั้ง** ใน session ใหม่ (อย่าใช้ session เดิม) — ฉาก 2 ถ้าอยากได้ "พิมพ์สด" ให้พิมพ์ใน session ทดสอบ แล้ว copy ข้อความตอบมาโชว์ ถ้าไม่อยากเสี่ยงคำตอบไม่ตรงสคริปต์ ใช้วิธีเลื่อนดู session เก่าแทน (แนะนำ — ควบคุมได้)
3. เช็คหน้าจอ: ปิด notification, ปิดแท็บส่วนตัว, ซูมฟอนต์ terminal (⌘+) ให้คนดูอ่านออก, ธีมมืด
4. อัดหน้าจอ 1440p ขึ้นไป 30fps, เสียงพูดแยกไมค์
5. ตัดต่อ: ครอปช่วงพิมพ์ยาว ๆ, ใส่ซูมเข้าจุดสำคัญ (ตัวเลข 4.33/3.67/7.00, diff, คำว่า "ยังไม่ใช่ครับ")
6. เช็คก่อนส่ง: ทุกหน้าจอที่โผล่ต้องไม่มี tab/แจ้งเตือน/ชื่อโปรเจกต์อื่น — ดูรอบเดียวจบ
