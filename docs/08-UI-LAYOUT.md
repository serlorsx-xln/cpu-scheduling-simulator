# 8. UI Layout และพฤติกรรมหน้าจอ

> ข้อความ error / styling / a11y อยู่ที่ [09-UI-VALIDATION-UX](09-UI-VALIDATION-UX.md) · กฎ validation ที่ [02-REQUIREMENTS §2.5](02-REQUIREMENTS.md) · design system ฉบับเต็มที่ [DESIGN.md](../DESIGN.md)

## 8.1 แนวคิด

Dashboard มาตรฐานของเครื่องมือจำลอง (แผงตั้งค่าซ้าย · ผลลัพธ์ขวา) ทำให้ประณีตระดับ production ในธีมมืด — มาตรฐานคุณภาพอ้างอิง Raycast/Arc และ Stripe dashboard ทุกอัลกอริทึมใช้สเกลเวลาเดียวกัน (makespan = ΣBT เท่ากันทุกอัลกอริทึมเมื่อ AT = 0) ตารางแบบเดียวกัน และไฮไลต์โปรเซสร่วมกัน เพื่อให้ "การเปรียบเทียบ" เป็นแกนของหน้า

## 8.2 Layout

```
┌ App bar (sticky 56px) ───────────────────────────────────────────────┐
│ [โลโก้] CPU Scheduling Simulator │ คำอธิบาย      ⌘/Ctrl ↵ คำนวณ  [SET-A] │
├──────────────────────┬───────────────────────────────────────────────┤
│ แผงตั้งค่า (360px)    │ ผลลัพธ์                                         │
│ sticky, เนื้อหาเลื่อน  │ ├ ErrorSummary (เมื่อ validation ไม่ผ่าน)        │
│ ภายใน ปุ่มติดล่าง      │ ├ หัว "ผลลัพธ์" + ชุดข้อมูลที่ใช้ + แจ้งเตือนค่าเปลี่ยน │
│  · จำนวนโปรเซส        │ ├ เปรียบเทียบเวลารอ (≥ 2 อัลกอริทึม)             │
│  · Burst Time         │ │   AVG WT ต่ออัลกอริทึม │ WT รายโปรเซส          │
│  · อัลกอริทึม + q      │ └ การ์ดต่ออัลกอริทึม × n                        │
│  [คำนวณผลลัพธ์]        │     Gantt + แถวราย process + ตาราง + สูตร       │
│  [ล้างค่า]            │ (ยังไม่คำนวณ → empty state พร้อมโครงกราฟ)        │
└──────────────────────┴───────────────────────────────────────────────┘
```

- จอ ≥ 1024px: 2 คอลัมน์ แผงตั้งค่า sticky สูงไม่เกินจอ เนื้อหาเลื่อนภายใน ปุ่มคำนวณ/ล้างค่าติดล่างของแผงเสมอ (แม้ 10 โปรเซส + error)
- จอเล็ก: ฟอร์มบน ผลลัพธ์ล่าง + แถบปุ่ม "คำนวณผลลัพธ์" ติดขอบล่าง ซึ่งจะซ่อนเองเมื่อปุ่มในแผงมองเห็นอยู่ (ไม่มีปุ่มหลักซ้อนสองปุ่ม); คำนวณแล้วเลื่อนไปที่ผลลัพธ์อัตโนมัติ
- ทดสอบแล้วไม่มี scroll แนวนอนที่ 1440 / 1280 / 390 / 360px

## 8.3 แผงตั้งค่า

**จำนวนโปรเซส** — stepper (−/ช่องตัวเลข/+ ช่วง 1–10) + ToggleGroup ลัด 3 / 5 / 10; คำใบ้ "สร้าง P1–Pn ให้อัตโนมัติ · สูงสุด 10"

**Burst Time** — Tabs "สุ่มอัตโนมัติ / กรอกเอง" + ปุ่ม "สุ่มใหม่" (โหมดสุ่ม, มี tooltip)
- แต่ละแถว: ป้าย Pk · ช่องตัวเลข · แถบสัดส่วน BT (เห็นงานสั้น/ยาวก่อนคำนวณ); ≥ 6 โปรเซสจัด 2 คอลัมน์
- ใต้รายการ: "Arrival Time = 0 ทุกโปรเซส" และ ΣBT เมื่อค่าถูกต้องครบ
- โหมดสุ่ม: ช่อง readonly แสดงค่าที่ใช้คำนวณจริง; สลับเข้าโหมดสุ่มหรือเพิ่มจำนวนโปรเซสในโหมดสุ่ม → ช่องที่ว่างหรือค่าไม่ถูกต้องได้ค่าสุ่มใหม่ ค่าที่ถูกต้องคงไว้

**อัลกอริทึม** — 3 แถว Checkbox (label ทั้งแถวกดได้) พร้อมจุดสีประจำอัลกอริทึม; เลือก RR → แถว Time Quantum (stepper, default 2) ขยายอยู่ในแถว RR

**ปุ่ม** — "คำนวณผลลัพธ์" (primary), "ล้างค่า" (ghost) · Enter ในฟอร์ม และ ⌘/Ctrl+Enter ที่ใดก็ได้ในหน้า = คำนวณ · ล้างค่า = n 3, โหมดสุ่ม, ทุกอัลกอริทึม, q 2

**ชุดตัวอย่าง SET-A** (ปุ่มที่แถบบนและใน empty state) — ตั้งค่า P1=5, P2=3, P3=8, q=2 ทุกอัลกอริทึม แล้วคำนวณทันที (ชุดเดียวกับ [07-HAND-CALCULATION](07-HAND-CALCULATION.md))

## 8.4 ผลลัพธ์

**หัวผลลัพธ์** — จำนวนโปรเซส · BT ที่ใช้คำนวณ · รวมหน่วยเวลา; ถ้าแก้ฟอร์มหลังคำนวณ จะขึ้น "ค่าในฟอร์มเปลี่ยนแล้ว" + ปุ่มคำนวณใหม่ (ผลลัพธ์ที่เห็นไม่ถูกเข้าใจผิดว่าเป็นของค่าใหม่)

**เปรียบเทียบเวลารอ** (เลือก ≥ 2 อัลกอริทึม)
- ประโยคสรุปคำนวณจากตัวเลขจริง เช่น "Shortest Job First มีเวลารอเฉลี่ยต่ำสุด (3.67) — น้อยกว่า Round Robin 3.33 หน่วยเวลา"
- AVG WT ต่ออัลกอริทึม: แท่งแนวนอนเริ่มที่ 0 ค่าชิดขวา อันต่ำสุดมีไอคอน ✓ + "ต่ำสุด" และ AVG TAT ใต้แท่ง; ชื่ออัลกอริทึมเป็นลิงก์ไปการ์ดของมัน
- WT รายโปรเซส: แถวละโปรเซส แท่งย่อยต่ออัลกอริทึม ค่าอยู่ปลายแท่ง มีเส้นกริดและแกนสเกล (ขั้นหารสวย เริ่ม 0)

**การ์ดต่ออัลกอริทึม** (เรียง FCFS → SJF → RR เสมอ)
- หัว: จุดสี · ชื่อเต็ม · ชื่อย่อ · q (RR) · กฎการเลือกโปรเซส · AVG TAT และ AVG WT ตัวใหญ่ ("รอเฉลี่ยน้อยที่สุด" เมื่อเป็นอันดับหนึ่ง)
- **Gantt Chart แบบตำราเรียน**: แถว CPU เป็น segment ต่อกันพร้อมป้าย Pk (แสดงเมื่อกว้าง ≥ 15px), เลขเวลาใต้ **ทุกขอบ segment** (กรองเฉพาะเมื่อชิดกันเกิน 22px แต่คง 0 และ makespan เสมอ)
- **แถวราย process**: แท่งสีอัลกอริทึม = ช่วงได้ CPU, แถบจาง = ช่วงรอ (ผลรวม = WT), ขีดตั้ง = CT, ค่า WT ที่ขอบขวา (จอ ≥ 640px)
- **เคอร์เซอร์เวลาร่วม**: ชี้บนไทม์ไลน์หรือโฟกัสแล้วใช้ ←/→ (Shift = ก้าวใหญ่, Home/End, Esc) → แถบหน่วยเวลาขอบคมพาดทุกแถว + ธงเวลา "t–t+1" บนแกน + ข้อความ "P1 ใช้ CPU · รอคิว P2, P3 · เสร็จแล้ว …" (aria-live) — ทุกอัลกอริทึมแสดงเวลาเดียวกันพร้อมกัน
- **โฟกัสโปรเซส**: ชี้/แตะโปรเซสที่ segment, แถวตาราง, แถวราย process หรือกราฟ WT รายโปรเซส → โปรเซสนั้นเด่นทุกกราฟ อื่นจางลง; คลิกเพื่อปักค้าง คลิกซ้ำเพื่อยกเลิก
- **ตาราง** Process | BT | ST | CT | TAT | WT (shadcn Table, หัวคอลัมน์มี tooltip อธิบายตัวย่อ) + แถว "เฉลี่ย" + บรรทัดสูตร `AVG WT = ΣWT ÷ n = 21 ÷ 3 = 7.00` ให้เทียบกับการคำนวณมือได้ทันที

**Empty state** — อธิบายสิ่งที่จะได้, ปุ่ม "คำนวณด้วยค่าปัจจุบัน" / "ลองชุดตัวอย่าง SET-A" และภาพโครง Gantt + แถวราย process (decoration, `aria-hidden`)
