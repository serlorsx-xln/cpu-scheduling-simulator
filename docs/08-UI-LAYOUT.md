## 8.1 ภาพรวม Layout

- จอเล็ก: คอลัมน์ซ้อนกัน (ฟอร์มบน ผลลัพธ์ล่าง)
- ยังไม่คำนวณ: คอลัมน์ขวาแสดง empty state (กรอบเส้นประ + คำแนะนำ)

## 8.2 พฤติกรรมฟอร์ม (การ์ดเดียว 3 สเต็ป)

**01 จำนวนโปรเซส** — ช่องเลขกลางช่อง + ปุ่ม chip ลัด 3 / 5 / 10 เปลี่ยนค่า/สร้างแถว P1…Pn ทันที (คงค่า BT เดิมตาม index)

**02 Burst Time** — segmented control 2 ปุ่ม (สุ่มอัตโนมัติ / กรอกเอง) + ปุ่ม ⟳ สุ่มใหม่เมื่ออยู่โหมดสุ่ม
- โหมดสุ่ม: ช่อง input readonly แสดงค่าที่ใช้คำนวณจริง (ตัวเลขชิดขวา font mono)
- ตาราง BT: แถวมีจุดสีบอกสถานะ (เทา = ปกติ แดง = ผิด) แถวผิดมี inline error

**03 อัลกอริทึม** — การ์ดเลือก 3 ใบซ้อนกัน (checkbox ซ่อนแบบ sr-only, label ทั้งใบคลิกได้):
- เลือกแล้ว: พื้นสีอ่อนประจำอัลกอริทึม + ring 2px + จุดสีเข้ม + ✓
- ยังไม่เลือก: ขอบเทา จุดจาง สัญลักษณ์ ○
- เลือก RR → แสดง Time Quantum แบบ stepper (ปุ่ม − / + ปรับทีละ 1 ขั้นต่ำ 1) default 2

**ปุ่ม** — "คำนวณผลลัพธ์" เต็มความกว้างปุ่มดำ (slate-900), "ล้างค่า" แบบ ghost
- กด Enter ในฟอร์ม = คำนวณ (form submit → handleCalculate)
- ล้างค่า: reset ทุก state (n=3, โหมดสุ่ม, ทุกอัลกอริทึม, q=2)

## 8.3 พฤติกรรมผลลัพธ์

- **ErrorSummary** (โซน error): กล่องแดง bullet ทุกข้อ ผลลัพธ์เดิมถูกล้าง
- **แผงเปรียบเทียบ AVG WT**: แสดงเมื่อเลือก ≥ 2 อัลกอริทึม — แท่งบาร์แนวนอนกว้าง ∝ AVG WT (เทียบกับค่าแย่สุด) อัลกอริทึมที่น้อยสุดมี badge "ต่ำสุด" สีเขียว
- **การ์ดผลลัพธ์ต่ออัลกอริทึม**: header (จุดสี + ชื่อ + chip q = 2 เฉพาะ RR) → ตาราง → stat block AVG WT (ใหญ่ สีดำ) / AVG TAT (รอง สีเทา) → Gantt chart; การ์ดมี animation fade-up ไล่ delay ตามลำดับ
- ตารางเรียง P1…Pn เสมอ, ตัวเลขใช้ font mono ชิดขวา, คอลัมน์ WT หนาสุด
- Gantt: segment มุมมนเว้นช่องไฟ สีตาม palette ของ processId, กว้าง ∝ ระยะเวลา, label แสดงเมื่อ segment กว้างพอ (≥9%), hover ขยายสูง + tooltip `P1: 0–5`
- ทุกการ์ดใช้ชุดข้อมูลเดียวกัน เปรียบเทียบได้ในหน้าเดียว
