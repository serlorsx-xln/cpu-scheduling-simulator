# 2. ความต้องการเชิงหน้าที่ (Functional Requirements)

> ตรงกับข้อกำหนดโจทย์หัวข้อ 1.1–1.5 · UI อ้างอิง [08-UI-LAYOUT](08-UI-LAYOUT.md) · กฎ validation ใช้จริงใน `lib/validation.ts`

## 2.1 การกำหนดโปรเซส (โจทย์ 1.1)

- ผู้ใช้กรอก **จำนวนโปรเซส (n)** เช่น 3, 5, 10 (จำกัด 1–10)
- ระบบสร้างแถวกรอกข้อมูลชื่อ **P1, P2, …, Pn** อัตโนมัติตามลำดับ
- **Arrival Time = 0** ทุกโปรเซส (ไม่รับ input — ระบุเป็นหมายเหตุบนหน้าเว็บ)

## 2.2 การกำหนด Burst Time (โจทย์ 1.2)

เลือกได้ 2 โหมดด้วย radio button:

| โหมด | พฤติกรรม |
|---|---|
| สุ่มอัตโนมัติ | สุ่มจำนวนเต็มบวกช่วง 1–10 ใส่ตาราง มีปุ่ม "สุ่มใหม่" สุ่มซ้ำได้ |
| กรอกด้วยตนเอง | ช่อง input ต่อโปรเซส ผู้ใช้กรอกเอง |

- โปรแกรมต้องตรวจสอบความถูกต้องทั้งจำนวนโปรเซสและ BT (ดู §2.5)

## 2.3 การเลือกอัลกอริทึม (โจทย์ 1.3)

- Checkbox เลือกได้มากกว่า 1 อัลกอริทึม: **FCFS**, **SJF (Non-preemptive)**, **Round Robin**
- เลือก RR → ต้องกรอก **Time Quantum** (ค่าเริ่มต้น 2, แก้ได้ก่อนคำนวณ, ต้องเป็นจำนวนเต็มบวก)
- ปุ่ม "คำนวณ" ประมวลผลทุกอัลกอริทึมที่เลือก **ด้วยชุดข้อมูลเดียวกัน** เพื่อเปรียบเทียบ

## 2.4 ผลลัพธ์ (โจทย์ 1.4)

แสดงเป็นการ์ดแยกต่ออัลกอริทึมที่เลือก (FCFS / SJF / RR) แต่ละการ์ดมี:

### ตารางรายโปรเซส — คอลัมน์บังคับ

| Process | BT | ST | CT | TAT | WT |
|---|---|---|---|---|---|
| P1 | 5 | 0 | 5 | 5 | 0 |

- **Process** — ชื่อโปรเซส P1, P2, …
- **BT** — Burst Time เวลาที่ต้องการใช้ CPU
- **ST** — Start Time เวลาที่ได้ใช้ CPU **ครั้งแรก** (สำคัญกับ RR ที่ได้ CPU หลายครั้ง)
- **CT** — Completion Time เวลาที่ทำงานเสร็จสมบูรณ์
- **TAT** — Turnaround Time
- **WT** — Waiting Time

### สูตรบังคับ

```
TAT = CT − AT        (เมื่อ AT = 0 → TAT = CT)
WT  = TAT − BT
AVG WT = ΣWT ÷ n     ← ค่าที่โจทย์บังคับให้รายงานทุกอัลกอริทึม (ทศนิยม 2 ตำแหน่ง)
```

### ส่วนเสริม

- **AVG TAT** — แสดงควบคู่เพื่อใช้อภิปรายเปรียบเทียบในรายงาน
- **Gantt Chart** — แถบไทม์ไลน์ CPU พร้อมช่วงเวลากำกับ ช่วยดูลำดับการทำงาน

> ค่าอ้างอิงจากการคำนวณมืออยู่ที่ [07-HAND-CALCULATION](07-HAND-CALCULATION.md)

## 2.5 การตรวจสอบข้อมูล (โจทย์ 1.5)

| รหัส | กรณี | ข้อความแจ้งเตือน |
|---|---|---|
| E1 | ไม่กรอกจำนวนโปรเซส | กรุณากรอกจำนวนโปรเซส |
| E2 | จำนวนโปรเซสเป็น 0 / ติดลบ / ไม่ใช่จำนวนเต็ม | จำนวนโปรเซสต้องเป็นจำนวนเต็มบวก |
| E3 | จำนวนโปรเซส > 10 | จำนวนโปรเซสต้องไม่เกิน 10 |
| E4 | BT ของโปรเซสใดไม่ใช่จำนวนเต็มบวก | Burst Time ของ P{k} ต้องเป็นจำนวนเต็มบวก |
| E5 | กรอก BT ไม่ครบหลายแถว | กรุณากรอก Burst Time ให้ครบทุกโปรเซส |
| E6 | Time Quantum ไม่ใช่จำนวนเต็มบวก (เมื่อเลือก RR) | Time Quantum ต้องเป็นจำนวนเต็มบวก |
| E7 | ไม่เลือกอัลกอริทึมใดเลย | กรุณาเลือกอัลกอริทึมอย่างน้อย 1 แบบ |

**กฎการแสดงผล:**
- ข้อความ error แสดงแบบ inline ใต้ช่องที่ผิด + รวมเป็นกล่องสรุปเหนือผลลัพธ์ (ไม่ใช้ `alert()`)
- กรณี BT ว่าง: แถวเดียวใช้ E4 ระบุโปรเซส, หลายแถวใช้ E5
- Validation ไม่ผ่าน → **ไม่คำนวณ** และไม่แสดงผลลัพธ์เก่าค้างไว้
